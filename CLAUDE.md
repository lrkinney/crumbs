# CRUMBS quick context

Meal-planning prototype. Expo SDK 58 / React Native / TypeScript / Expo Router, exported to web and hosted on Vercel (https://crumbs-phi-three.vercel.app, auto-deploys from `main` of `lrkinney/crumbs`). See `AGENTS.md` for Expo rules.

## Working rules (keep sessions cheap)
- Web is the deliverable. Skip native checks unless asked.
- Don't touch Figma unless asked to sync. Figma file "CRUMBS Screens", key `61rO5dmZy6bsxQXUkKw0SH`.
- Run `npm run check` once before a push; otherwise only the relevant test or `npm run typecheck`.
- Visual checks only for screens the user names. Commit and push only when asked.
- One screen or change per session where possible.

## Layout
- `src/features/` screens, `src/components/ui/` shared UI, `src/services/` logic (planning, etc.), `src/theme/` tokens (generated by `npm run tokens`).
- `data/recipes.json` (32 recipes, schema v2) and `data/ingredients.json`; validate with `npm run library:validate`. Adding recipes: `docs/adding-recipes.md`.
- `scripts/` estimate and import tooling. Price/nutrition estimates are approximate Boston, MA values, not live quotes.
- Recipe plates: use `recipePlate(recipe, 'hero'|'tile')` (normalised square PNGs in `assets/crumbs/plates/`, regenerate with `scripts/normalize-plates.py`, needs Pillow). Don't use the raw Figma exports except in onboarding.
- `design-system/` handoff docs, e.g. `home-rebuild.md`.
